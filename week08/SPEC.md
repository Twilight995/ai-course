# SPEC.md

## 1. 기술과 파일 구성

### 기술 스택
- **Language**: Python 3.10 이상
- **Framework**: Flet 1.0 (기본 제공되는 문법만 사용)
- **Constraint**: 외부 패키지 사용 금지 (Python 표준 라이브러리만 사용 가능)
- **Flet UI Restriction**: 
  - Flet 1.0 기본 뼈대 문법 내의 컴포넌트(`TextField`, `Dropdown`, `Checkbox`, `Text`, `Button`, `ListView`, `Row`)만 사용한다.
  - 아래 항목은 절대 사용하지 않는다: `ft.app(...)`, `ft.colors`, `ft.alignment.center`, `ft.ElevatedButton`, `Button(text=...)`, `page.window_width`, `ft.UserControl`, `TextField(error_text=...)`

### 파일 구성
| 파일명 | 역할 | 비고 |
| :--- | :--- | :--- |
| `SPEC.md` | 프로그램 상세 설계 명세서 | 본 문서 |
| `logic.py` | 입력 검증 및 요금 계산 로직 | Flet을 import하지 않음 |
| `main.py` | Flet 기반 UI 구현 및 화면 표시 | `logic.py`의 기능을 호출하여 사용 |
| `test_logic.py` | `logic.py` 단위 테스트 수행 | 테스트 통과/실패 건수 출력 |

## 2. 동작 규칙

### 입력 검증 프로세스
사용자가 [계산] 버튼을 누르면 `logic.py`에서 다음 순서로 검사하며, 가장 먼저 걸리는 오류 메시지를 반환한다.
1. **입차 빈칸**: 입차 입력란이 비어 있는 경우 → "입차 시각을 입력해주세요"
2. **입차 형식**: 입차 입력란의 형식이 `"HH:MM"`이 아닌 경우 → "입차 시각 형식이 올바르지 않습니다 (예: 09:05)"
3. **출차 빈칸**: 출차 입력란이 비어 있는 경우 → "출차 시각을 입력해주세요"
4. **출차 형식**: 출차 입력란의 형식이 `"HH:MM"`이 아닌 경우 → "출차 시각 형식이 올바르지 않습니다 (예: 09:05)"
5. **같은 시각**: 입차 시각과 출차 시각이 동일한 경우 → "출차는 입차보다 뒤여야 합니다"

### 시각 형식
- `"HH:MM"` 24시간제. 시와 분은 반드시 두 자리씩 쓴다. 시는 00~23, 분은 00~59만 허용한다.
- 입력값 앞뒤 공백은 지우고 검사한다. 지운 뒤 빈 글자이면 빈칸으로 본다.

### 요금 규칙
- 주차 시간이 30분 이하면 0원이다.
- 30분을 넘으면 (주차 시간 - 30)분을 10분 단위로 올림해서 단위마다 500원이다. 예: 31분 500원, 40분 500원, 41분 1,000원, 60분 1,500원.
- 한 번 주차한 요금은 20,000원을 넘지 않는다. (7시간 10분에서 20,000원이 되고, 그 뒤로는 20,000원으로 고정)
- 출차가 입차보다 앞선 경우(예: 23:00 → 01:00) 다음 날로 간주하여 계산한다.

### 로직 함수 명세 (`logic.py`)
1. **`calculate_parking_fee(in_time, out_time)`**
   - **입력**: 입차 시각 문자열, 출차 시각 문자열
   - **성공 시 반환**: `(result_dict, None)` 
     - `result_dict = {"in": "09:30", "out": "11:05", "duration": "1시간 35분", "fee": 3500}`
     - `in`, `out`은 앞뒤 공백을 지운 시각이다. `duration`은 항상 `"X시간 Y분"` 형식이다(1시간 미만도 `"0시간 30분"`). `fee`는 정수다.
   - **실패 시 반환**: `(None, "안내 문구")`

2. **`calculate_total_sum(fee_list)`**
   - **입력**: 요금(정수)들이 담긴 리스트
   - **반환**: `"합계: X,XXX원"` 형태의 문자열 (목록이 비어있으면 `"합계: 0원"`)

3. **`format_row(result_dict)`**
   - **입력**: `calculate_parking_fee`가 돌려준 `result_dict`
   - **반환**: 목록 한 줄 글자 `"입차 09:30 → 출차 11:05, 1시간 35분, 3,500원"`

### 목록 관리
- **목록 출력**: 계산에 성공할 때마다 `format_row`의 글자를 목록 맨 아래에 추가하고, 합계를 다시 계산한다.
- **삭제 기능**: 각 목록 줄에는 삭제 버튼이 포함된다. 버튼 클릭 시 해당 항목을 목록에서 제거하고, `calculate_total_sum`을 다시 호출하여 합계를 갱신한다.
- 오류가 나면 목록에 추가하지 않고, 빨간 안내 문구만 보여 준다. 계산에 성공하면 안내 문구를 지운다.

## 3. 화면 구성

화면은 상단에서 하단으로 다음과 같이 배치된다. 창 제목은 "주차 요금 계산기"이고 크기는 420x600, 크기 조절은 막는다.

1. **합계 영역**: `Text` 컴포넌트, 크고 굵은 글자 (예: "합계: 3,500원")
2. **입력 영역**:
   - `Row` 한 줄에 `TextField` (라벨 "입차 시각")와 `TextField` (라벨 "출차 시각")를 나란히 놓는다.
   - `Button` (텍스트: "계산", 파란 바탕에 흰 글자). `Row`로 감싸 가로로 넓게 놓는다.
   - `Text` (에러 메시지 표시용, 검사 실패 시 빨간색 문구 출력)
3. **목록 영역**: `ListView`
   - 각 항목은 `Row`로 구성되며, 목록 한 줄 글자와 삭제용 `Button`(텍스트: "삭제")을 포함한다.
