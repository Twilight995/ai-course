# 공공복지격차맵

스마트폰에서 내 시군구를 고르면 의료·돌봄·도서관 7개 영역이 부족한지 넉넉한지를 카드로 보여 주고, 전국 230곳을 색칠 지도 한 장으로 견주어 보여 주는 모바일 웹.

## 여는 주소
https://twilight995.github.io/ai-course/week15/

스마트폰 브라우저에서 바로 열린다. 설치할 것은 없다.

## 왜 만들었나
공공데이터는 공개돼 있지만 스마트폰에서는 쉼표로 가득한 CSV 라 읽을 수 없다. 시설 한 곳씩의 줄만 있어서 우리 지역이 어떤 편인지는 직접 세고 다른 지역과 견줘야 안다. 1~5단계에서는 도서관 한 영역만 보여 주었고, 6단계부터 7개 영역으로 넓혔다. 10단계에서 스마트폰으로 보니 점 지도는 지역을 구분하기 어려워, 11단계부터 시군구 경계를 색으로 칠한 지도로 바꾸고 화면을 다듬었다. 13단계까지는 Flask 로 만들어 PC 를 켜 둬야만 열렸다. 14단계부터는 GitHub Pages 에 올릴 수 있게 서버 없이 열리는 정적 페이지로 바꿨다.

## 화면
- 주소 그대로 : 전국 색칠 지도와 부족한 영역이 많은 곳 목록. 구역이나 목록의 줄을 누르면 지역 화면으로 간다
- #sido=서울특별시 : 그 시도만 크게 보여 주는 지도와 시군구 목록
- #domain=access : 고른 영역 하나의 판정(부족·보통·넉넉)으로 칠한 지도. sido 와 함께 쓸 수 있다
- #region=서울특별시|관악구 : 지역 화면. 7개 영역 요약 상자, AI 요약, 영역 카드 7장, 알아 둘 점

## 어떻게 돌아가나
- 계산은 파이썬(logic.py)이 PC 에서 미리 한다. 그 결과를 자료 파일 site_data.js 한 개로 내보낸다.
- 화면 조각은 Flask 로 만든 화면을 PC 에서 한 번 그려 잘라 낸 것이다. 그래서 13단계까지 만든 계산, 화면 틀, 테스트를 그대로 쓴다.
- 스마트폰 브라우저의 JavaScript(view.js, summary.js)는 화면 조각을 끼워 넣고, 고른 영역에 맞게 지도 색을 바꾸고, 요약문을 받는 일만 한다. 판정 같은 계산은 하지 않는다.
- 외부 CSS, CDN, 라이브러리는 쓰지 않는다.

## AI 요약
1. 지역 화면을 열면 13주차 강의의 ask 함수로 실습 서버의 gemma4 를 부른다.
2. 답이 6초 안에 오고 검사를 통과하면 "AI 요약"으로 보여 준다.
3. 실패했거나 검사에 걸리면 PC 에서 gemma4 에게 미리 받아 둔 글을 "AI 요약 (미리 받아 둔 글)"로 보여 준다.

검사는 카드에 없는 숫자를 쓰거나, 부족하지 않은 영역을 말하거나, 뜻 없는 답이면 버린다. 미리 받아 둔 글 230개도 같은 검사를 통과한 것이다.
2026년 11월 27일 현재 실습 서버는 다른 주소의 웹페이지가 보내는 요청을 허용하지 않아(CORS), 스마트폰에서는 미리 받아 둔 글이 보인다. 서버가 허용하면 코드를 고치지 않아도 방금 받은 글이 보인다.

## 자료 파일을 다시 만드는 방법
pip install flask openai 를 한 뒤 week15 폴더에서 차례로 실행한다.
- python fetch_summaries.py : 230곳의 요약을 gemma4 에게 다시 받는다(10분쯤 걸린다). 받아 둔 글을 그대로 쓰려면 건너뛴다
- python make_site.py : site_data.js 를 다시 만든다
- 커밋하고 푸시하면 GitHub Pages 가 다시 올린다

## 테스트 방법
python test_logic.py (통과 150 / 전체 150), python test_app.py (통과 38 / 전체 38), python test_static.py (통과 24 / 전체 24)
JavaScript 는 브라우저에서 Flask 화면과 견주어 확인했다. 결과는 PROGRESS.md 에 있다.

## 파일 설명
- index.html: 머리띠와 화면 조각을 끼울 빈 자리
- view.js: 주소 읽기, 화면 조각 끼워 넣기, 지도 색 바꾸기
- summary.js: 요약 받기와 검사
- site_data.js: 화면 조각, 지도 색, 요약을 담은 자료 파일. make_site.py 가 만든다
- static/style.css: 화면 꾸밈 파일
- logic.py: 자료 읽기, 지역 카드, 색칠 지도, 요약문 검사
- build_site.py: 화면 조각을 자르고 링크를 바꾸는 함수, 요약 검사에 쓸 값 뽑기
- make_site.py: 화면 조각·지도 색·요약을 모아 site_data.js 를 쓴다
- fetch_summaries.py: 230곳의 요약을 미리 받아 data/gap_summaries.csv 에 쓴다
- app.py, templates/: Flask 판. 화면 조각을 만드는 데 쓰고, python app.py 로 PC 에서 띄울 수도 있다
- data/welfare_gap.csv: 시군구 230곳의 지표와 판정
- data/map_paths.csv, data/map_views.csv: 색칠 지도의 경계 모양과 시도별로 보이는 범위
- data/gap_summaries.csv: 미리 받아 둔 요약 230개
- test_logic.py, test_app.py, test_static.py: 테스트
- SPEC.md: 6단계부터의 명세 (1~5단계는 SPEC_v1.md)
- PROGRESS.md: 단계별 작업 기록
- screenshots/: 화면 그림 (v4_ 로 시작하는 7장이 지금 화면, v3_ 은 Flask 판의 색칠 지도, v2_ 는 점 지도 때, 나머지 4장은 1~5단계)

## 자료 출처와 만든 방법
2022년 이후 공공데이터만 썼다. 공공데이터포털(건강보험심사평가원 병의원·약국 현황, 보건복지부 사회복지시설 정보, 분만 가능 의료기관 목록, 국가도서관통계, 시군구별 수급권자 현황, 어린이집 목록, 국립중앙의료원 헬스맵, 행정안전부 주민등록 인구, 국가데이터처 인구 격자)과 복지로 복지통계(등록장애인)에서 받았다. 지도의 경계선은 국가데이터처 SGIS(2025년 2분기)의 것을 줄여서 넣었다.
수집과 집계는 이 앱과 별도의 분석 작업에서 했다. 시군구마다 인구에 견준 지표를 만들고, 비지도학습(K-Means)으로 지역 유형 3가지를 나누고, 지도학습(회귀)으로 인구 구조가 비슷한 지역의 기대값을 구해 부족·비슷·넉넉·경계를 붙였다. 앱은 그 결과 파일(data/welfare_gap.csv)을 읽기만 한다.

## AI 를 쓴 곳과 사람이 한 일
- 개발: Cline + 실습 서버 gemma4. 단계마다 테스트를 먼저 쓰고 통과한 뒤 다음 단계로 갔다.
- 요약문: gemma4 가 지역 카드를 두 문장으로 풀어 쓴다.
- gemma4 가 파일 가운데를 고치다 여러 번 틀렸다(함수를 다른 함수 가운데에 넣음, 따옴표와 줄 번호를 잘못 씀, 테스트 줄을 빠뜨림, 파일 내용을 되풀이해 붙임). 그때마다 테스트로 잡아 되돌렸고, 작업을 더 잘게 나누거나 한두 줄은 사람이 고쳤다. 자세한 기록은 PROGRESS.md 에 있다.

## 한계
- 판정은 인구에 견준 시설·인력의 양이다. 질, 운영 시간, 실제 이용 편의는 담지 못한다.
- 부족과 넉넉은 계산을 되풀이해도 답이 같을 때만 붙이고 나머지는 보통으로 본다. 그래서 기준선 가까이 있는 지역은 보통으로 나오고, 카드에 그 안내를 적는다.
- 의료거리는 정부의 2023년 값이고 나머지는 2024~2026년 자료라 기준 시점이 섞여 있다.
- 인천의 새 4개 구는 일부 값이 추정이고, 지도 경계는 읍면동을 다시 묶은 것이다. 경계선은 2025년 6월 기준이다.
- 작은 섬은 지도에서 빠져 있다. 넓은 군이 눈에 크게 띄지만 넓이는 주민 수와 상관없다.
- 지도는 끌거나 확대할 수 없다. 시도를 골라서 크게 본다.
- 자료 파일이 약 4.6MB 다(전송할 때는 압축되어 약 0.5MB). 처음 열 때 한 번 받는다.
- 스마트폰에서 방금 받은 AI 요약은 실습 서버가 허용 설정을 켜야 나온다. 그 길은 브라우저에서 서버의 답을 흉내 내어 확인했고, 진짜 서버로는 확인하지 못했다.
- 요약문 검사는 숫자와 영역 이름만 본다. 이름표의 낱말이 바뀐 것은 잡지 못한다.
- 도서관 자세히 화면과 금연 화면은 Flask 판에만 있다. 도서관 자세히는 1~5단계의 기준이라 격차맵 카드와 판정이 다르게 나올 수 있어 정적 페이지에는 넣지 않았다.
