# 공공복지격차맵

스마트폰에서 내 시군구를 고르면 의료·돌봄·도서관 7개 영역이 부족한지 넉넉한지를 카드로 보여 주고, 전국 230곳을 점 지도 한 장으로 견주어 보여 주는 모바일 웹.

## 왜 만들었나
공공데이터는 공개돼 있지만 스마트폰에서는 쉼표로 가득한 CSV 라 읽을 수 없다. 시설 한 곳씩의 줄만 있어서 우리 지역이 어떤 편인지는 직접 세고 다른 지역과 견줘야 안다. 1~5단계에서는 도서관 한 영역만 보여 주었고, 6단계부터 7개 영역으로 넓혔다. 금연 지원 표는 시도 단위 자료라 시군구 지도와 맞지 않아 메뉴에서 뺐다(주소 /smoking 과 테스트는 남겨 두었다).

## 실행 방법
pip install flask openai → python app.py → 같은 와이파이의 스마트폰에서 http://PC주소:5000

## 화면
- / : 전국 점 지도와 부족한 영역이 많은 곳 목록. 시도를 고르면 그 시도의 점 지도와 시군구 목록
- /region : 지역 화면. 영역 카드 7장, AI 요약, 알아 둘 점
- /library : 도서관 자세히(1~5단계에서 만든 화면)

## 테스트 방법
python test_logic.py (통과 130 / 전체 130), python test_app.py (통과 32 / 전체 32)

## 파일 설명
- app.py: Flask 웹 서버
- logic.py: 자료 읽기, 지역 카드, 점 지도, 요약문 검사
- templates/: 화면 틀 (home.html, region.html, index.html, smoking.html)
- data/welfare_gap.csv: 시군구 230곳의 지표와 판정
- test_logic.py, test_app.py: 테스트
- SPEC.md: 6단계부터의 명세 (1~5단계는 SPEC_v1.md)
- PROGRESS.md: 단계별 작업 기록
- screenshots/: 화면 그림 (v2_ 로 시작하는 7장이 격차맵, 나머지 4장은 1~5단계)

## 자료 출처와 만든 방법
2022년 이후 공공데이터만 썼다. 공공데이터포털(건강보험심사평가원 병의원·약국 현황, 보건복지부 사회복지시설 정보, 분만 가능 의료기관 목록, 국가도서관통계, 시군구별 수급권자 현황, 어린이집 목록, 국립중앙의료원 헬스맵, 행정안전부 주민등록 인구, 국가데이터처 인구 격자)과 복지로 복지통계(등록장애인)에서 받았다.
수집과 집계는 이 앱과 별도의 분석 작업에서 했다. 시군구마다 인구에 견준 지표를 만들고, 비지도학습(K-Means)으로 지역 유형 3가지를 나누고, 지도학습(회귀)으로 인구 구조가 비슷한 지역의 기대값을 구해 부족·비슷·넉넉·경계를 붙였다. 앱은 그 결과 파일(data/welfare_gap.csv)을 읽기만 한다.

## AI 를 쓴 곳과 사람이 한 일
- 개발: Cline + 실습 서버 gemma4. 단계마다 테스트를 먼저 쓰고 통과한 뒤 다음 단계로 갔다.
- 요약문: gemma4 가 지역 카드를 두 문장으로 풀어 쓴다. 카드에 없는 숫자를 쓰거나, 부족하지 않은 영역을 말하거나, 뜻 없는 답이면 버리고 미리 정한 문장을 보여 준다.
- gemma4 가 파일 가운데를 고치다 여러 번 틀렸다(함수를 다른 함수 가운데에 넣음, 따옴표와 줄 번호를 잘못 씀). 그때마다 테스트로 잡아 되돌렸고, 작업을 더 잘게 나누거나 한두 줄은 사람이 고쳤다. 자세한 기록은 PROGRESS.md 에 있다.

## 한계
- 판정은 인구에 견준 시설·인력의 양이다. 질, 운영 시간, 실제 이용 편의는 담지 못한다.
- 인구 구조가 비슷한 지역과 견주는 영역은 기준선 가까이 있는 지역이 "경계"로 나온다.
- 의료거리는 정부의 2023년 값이고 나머지는 2024~2026년 자료라 기준 시점이 섞여 있다.
- 인천의 새 4개 구는 일부 값이 추정이다.
- 점 지도는 경계선 없이 주민이 모여 사는 중심에 점을 찍는다. 인천처럼 섬이 먼 시도는 점이 한쪽에 뭉친다.
- 요약문 검사는 숫자와 영역 이름만 본다. 이름표의 낱말이 바뀐 것은 잡지 못한다.

## 사용 모델
- 실습 서버 gemma4 (Cline 으로 개발, 요약문 생성에도 사용)
