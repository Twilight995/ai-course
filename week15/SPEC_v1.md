# SPEC.md

## 1. 불편했던 점
- 월요일 강의 수업 내용중 공공데이터 사용을 배우면서 여러 데이터들을 접했는데, 도서관과 금연에 관한 데이터가 눈에 들어왔고, 해당 내용으로 강의 실습을 했었다. 실습을 끝낸 뒤, 우리 동네에 도서관이 충분한지, 금연 지원이 잘 되고 있는지 스마트폰으로 알아보려 했다.
- 공공데이터포털에서 받을 수 있는 것은 CSV 파일뿐이다. 전국도서관표준데이터는 3,657줄(약 1.2MB), 국가금연지원서비스 니코틴의존도 2024는 239,386줄(약 27MB)이다.
- 스마트폰에서 이 파일을 열면 작은 화면에 글자와 쉼표만 가득 나온다. 가로와 세로로 계속 밀어야 하고, 우리 지역 줄을 찾기 어렵다.
- 줄을 찾아도 도서관 한 곳씩의 좌석 수, 책 수만 있다. 우리 지역에 큰 도서관이 몇 곳인지, 주말에 닫는 곳이 얼마나 되는지는 직접 세야 한다.
- 금연 자료는 한 사람당 한 줄이라 지역끼리 비교하려면 239,386줄을 직접 더해야 한다.
- 결국 공개된 자료인데도 스마트폰만 가진 보통 사람은 자기 지역 상황을 알 수 없다.
- 그리고 더 나아가 이것을 한눈에 보기 쉽게 만들어놓으면 우리나라의 지역 사이의 도서관·금연 지원 격차를 살펴보는데 도움이 될 것 같아서 해당 내용으로 선정하게되었다.

## 2. 해결 방법
- 원본을 미리 지역별로 집계해 둔 파일을 사용한다. (`data/library_gap.csv`, `data/smoking_resource.csv`) 집계는 다른 수업(월요일 강의)의 공공데이터 분석 실습에서 직접 만든 결과이며, 원본은 공공데이터포털의 전국도서관표준데이터(2026-10)와 국가금연지원서비스 니코틴의존도(2024)다.
- 스마트폰 브라우저에서 지역을 고르면 그 지역 도서관 숫자를 카드 한 장으로 보여준다.
- Gemma4가 카드의 숫자를 두 문장으로 풀어 써 준다.
- 금연 지원이 부족한 순서로 17개 시도를 한 표에 보여준다.

## 3. 만들 기능

| 불편한 점 | 해결 방법 | 만들 기능 |
| :--- | :--- | :--- |
| 스마트폰에서 방대한 CSV를 읽기 어려움 | 미리 집계된 지역별 CSV 사용 | 지역 선택(시도/시군구) 기능 |
| 지역별 도서관 현황 파악이 힘듦 | 도서관 정보를 요약된 카드로 제공 | 도서관 현황 카드 및 상태 색상 표시 |
| 숫자만 나열된 카드는 한눈에 뜻을 알기 어려움 | AI가 숫자를 문장으로 풀어 설명 | Gemma4 기반 도서관 현황 요약 문장 (지어낸 숫자 검사 포함) |
| 금연 데이터 지역별 비교 불가 | 금연 지원 부족 순위 표 제공 | 금연 지원 서비스 순위 표 |

## 4. 기술과 파일 구성
- **기술 스택:** Python, Flask, openai (실습 서버 Gemma4 호출)
- **제약 사항:** `pandas` 사용 금지 (표준 `csv` 모듈 사용), JavaScript 사용 금지, 외부 CSS/CDN 사용 금지
- **파일 구성:**
  - `app.py`: Flask 웹 서버
  - `logic.py`: 데이터 계산 및 처리 로직 (Flask 미포함)
  - `templates/index.html`: 도서관 정보 페이지
  - `templates/smoking.html`: 금연 지원 정보 페이지
  - `test_logic.py`: 로직 검증 테스트
  - `test_app.py`: Flask 앱 검증 테스트

## 5. 동작 규칙

### 도서관 카드 색상 및 문구 규칙
- **빨강:** 대형 거점 도서관이 0곳인 경우
- **주황:** 거점이 1곳이고 주말 휴관 비율이 50% 이상인 경우
- **초록:** 그 외의 경우 (균형)

### 안내 문구
- 지역을 선택하지 않았을 때: "지역을 선택해주세요"
- 시도가 비어 있을 때: "시도를 선택해주세요"
- 시군구가 비어 있을 때: "시군구를 선택해주세요"
- 해당 지역 데이터가 없을 때: "등록된 도서관 정보가 없습니다"

### 지역 찾기 규칙
- 같은 이름의 시군구(중구, 남구 등)가 여러 시도에 있으므로 시도와 시군구를 함께 써서 찾는다.
- 실제 데이터 229개 시군구 중 빨강은 1곳(완도군), 주황은 7곳(양양군, 진주시, 하동군, 함양군, 합천군, 상주시, 부산 남구)이다.

### 금연 지원 순위 표 규칙
- **정렬:** '1,000명당 캠프 이용 건수'가 적은 순 (지원이 부족한 지역이 상단에 위치)
- **열 구성:** 순위, 지역, 고의존 비율(%), 1,000명당 캠프 이용 건수
- **특이 사항:** 캠프 이용 건수가 0건인 경우 숫자 대신 "이용 기록 없음"으로 표시

### Gemma4 요약문 규칙
- 카드에 표시된 숫자만 사용하여 두 문장으로 작성한다.
- 카드에 없는 숫자가 포함되어 있거나 서버 오류가 발생하는 경우, 미리 정해진 안전한 문장을 반환한다.
- "충분하다", "부족하다"와 같은 주관적 평가는 정해진 상태 문구(거점 도서관 없음 / 거점 1곳 · 주말 휴관 많음 / 균형) 범위 내에서만 표현한다.
- 도서관 세는 단위는 "곳"을 사용한다.

## 6. 화면
- **공통:** 상단에 '도서관', '금연 지원' 메뉴 링크 배치
- **도서관 페이지 (`/`):** 
  - 시도(optgroup)와 시군구가 포함된 선택 상자(Select Box)
  - 선택된 지역의 도서관 숫자를 담은 카드
  - Gemma4의 요약 문장
- **금연 지원 페이지 (`/smoking`):** 
  - 17개 시도 순위 표

## 7. 단계 계획과 테스트

| 단계 | 만드는 것 | 테스트 방법 | 끝났다는 기준 |
| :--- | :--- | :--- | :--- |
| 1단계 | 도서관 데이터 계산 로직 (`logic.py`) | `python test_logic.py` | 통과 20 / 전체 20 |
| 2단계 | 금연 순위 계산 로직 (`logic.py`) | `python test_logic.py` | 통과 28 / 전체 28 |
| 3단계 | Gemma4 요약문 틀 및 숫자 검사 로직 (`logic.py`) | `python test_logic.py` | 통과 41 / 전체 41 |
| 4단계 | Flask 앱 및 HTML 화면 (`app.py`, `templates/`) | `python test_app.py` | 통과 7 / 전체 7 |
| 5단계 | 스마트폰 환경 최종 확인 | 같은 와이파이의 스마트폰 브라우저로 접속 | 확인표 5개 항목 통과 |

- 단계마다 테스트를 먼저 쓰고, 통과한 뒤에만 다음 단계로 간다.
- 이미 통과한 테스트는 고치지 않는다. 단계가 끝날 때마다 커밋한다.

## 8. 하지 않는 것과 한계
- **하지 않는 것:** 지도 그리기, 로그인 기능, 개인 정보 저장, 도서관 화면과 금연 화면 간 데이터 연결 (시도 명칭 불일치 때문), JavaScript 사용(Gemma4의 원활한 개발을 위해 최대한 필요없는 기술들을 덜어냄)
