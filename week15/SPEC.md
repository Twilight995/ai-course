# SPEC.md

1~5단계의 명세는 SPEC_v1.md 에 있다. 이 문서는 6단계부터의 명세(공공복지격차맵)다.

## 1. 불편했던 점
- 월요일 강의 수업 내용중 공공데이터 사용을 배우면서 여러 데이터들을 접했는데, 도서관과 금연에 관한 데이터가 눈에 들어왔고, 해당 내용으로 강의 실습을 했었다. 실습을 끝낸 뒤, 우리 동네에 도서관이 충분한지, 금연 지원이 잘 되고 있는지 스마트폰으로 알아보려 했다.
- 공공데이터포털에서 받을 수 있는 것은 CSV 파일뿐이다. 전국도서관표준데이터는 3,657줄(약 1.2MB), 국가금연지원서비스 니코틴의존도 2024는 239,386줄(약 27MB)이다.
- 스마트폰에서 이 파일을 열면 작은 화면에 글자와 쉼표만 가득 나온다. 가로와 세로로 계속 밀어야 하고, 우리 지역 줄을 찾기 어렵다.
- 줄을 찾아도 도서관 한 곳씩의 좌석 수, 책 수만 있다. 우리 지역에 큰 도서관이 몇 곳인지, 주말에 닫는 곳이 얼마나 되는지는 직접 세야 한다.
- 금연 자료는 한 사람당 한 줄이라 지역끼리 비교하려면 239,386줄을 직접 더해야 한다.
- 결국 공개된 자료인데도 스마트폰만 가진 보통 사람은 자기 지역 상황을 알 수 없다.
- 그리고 더 나아가 이것을 한눈에 보기 쉽게 만들어놓으면 우리나라의 지역 사이의 도서관·금연 지원 격차를 살펴보는데 도움이 될 것 같아서 해당 내용으로 선정하게되었다.
- 1~5단계에서는 도서관 한 영역만 보여 주었다. 6단계부터는 의료·돌봄·도서관 7개 영역으로 넓힌다.

## 2. 해결 방법
- 스마트폰에서 내 시군구를 고르면, 의료·돌봄·도서관 7개 영역이 부족한지 넉넉한지를 카드로 보여 주고, 전국 230곳을 점 지도 한 장으로 견주어 보여 주는 앱.
- 원자료를 미리 시군구별로 집계하고 판정까지 붙여 둔 파일(`data/welfare_gap.csv`)을 쓴다. 앱은 이 파일을 읽기만 한다.

## 3. 만들 기능

| 불편한 점 | 해결 방법 | 만들 기능 |
| :--- | :--- | :--- |
| 스마트폰에서 CSV를 읽을 수 없음 | 미리 집계한 파일을 화면으로 보여 줌 | 지역 고르기(시도 → 시군구) |
| 우리 지역이 어떤 편인지 직접 세어야 함 | 7개 영역의 판정과 근거 숫자를 카드로 | 지역 화면의 영역 카드 7장과 전국 중앙값 |
| 지역 사이의 격차가 한눈에 안 보임 | 전국 230곳을 점 지도 한 장으로 | 전국·시도 점 지도, 부족한 영역이 많은 곳 목록 |
| 판정만 보면 오해하기 쉬움 | 믿기 어려운 경우를 그 화면에서 알림 | "무엇에 비해" 한 줄, "알아 둘 점" |
| 숫자만 있으면 뜻을 알기 어려움 | AI가 두 문장으로 풀어 씀 | Gemma4 요약과 검사 3가지, 기본 문장 |

## 4. 기술과 파일 구성
- **기술 스택:** Python, Flask, openai (실습 서버 Gemma4 호출)
- **제약 사항:** `pandas` 사용 금지 (표준 `csv` 모듈 사용), JavaScript 사용 금지, 외부 CSS/CDN 사용 금지
- 모든 화면은 스마트폰 세로 화면(폭 360px 안팎)에서 가로로 밀지 않고 읽혀야 한다.

| 파일 | 바뀌는 것 |
| :--- | :--- |
| `logic.py` | 새 함수 추가(이름은 단계마다 프롬프트에서 정한다): 격차 자료 읽기, 시도·시군구 목록, 지역 카드 만들기(7영역 + 알아 둘 점), 전국 중앙값, 부족 많은 곳 목록, 지도 점 계산(전국/시도), 격차 요약 프롬프트·검사·기본 문장. 지금 함수는 고치지 않는다. |
| `app.py` | `/`(첫 화면·시도 화면), `/region`, `/library`(지금의 `/` 내용), `/smoking`(그대로) |
| `templates/` | `home.html`(첫 화면·시도 화면), `region.html`, `index.html`(도서관 자세히: 탭 제거, 양식이 보내는 곳을 `/library`로, 격차맵으로 가는 링크), `smoking.html`(탭 제거) |
| `test_logic.py` | 지금 41개는 그대로. 6~8단계 테스트를 뒤에 덧붙인다. |
| `test_app.py` | 1~5번이 부르는 주소만 `/library`로. 9단계 테스트를 뒤에 덧붙인다. |

**지도 그리기를 한 곳에 모은다**: "점들의 자리와 색을 받아 SVG 글자를 돌려주는 함수" 하나만 지도를 그린다. 화면 틀(템플릿)은 그 결과를 그대로 끼워 넣기만 한다. 나중에 진짜 지도로 바꿀 때 이 함수와 끼워 넣는 자리만 바꾸면 되게 하려는 것이다.

- 전국 지도: `map_x`, `map_y`를 그대로 쓴다(viewBox 0 0 1000 H, H는 자료의 y 최댓값에 여백을 더한 값).
- 시도 지도: 그 시도 점들의 범위를 구해 여백을 두고 같은 비율로 늘린다(가로세로 비율 유지).
- 좌표 계산은 Gemma4 없이 테스트할 수 있는 순수 함수로 둔다.

## 5. 자료

분석 폴더의 `data/gap/sigungu_gap.csv`를 바탕으로 `week15/data/welfare_gap.csv`(230줄, utf-8-sig)를 만든다. 칸을 고르고, 이름을 바꾸고, 몇 칸은 새로 계산한다. 이 파일은 분석 폴더의 스크립트(`분석_격차맵/export_app_data.py`)로 준비 단계에서 이미 만들어 넣었다. 이 파일은 만들지도 고치지도 않는다. 아래 칸 이름이 그대로 머리줄이 된다.

| 칸 | 뜻 |
| :--- | :--- |
| `sido`, `sigungu`, `pop` | 시도, 시군구, 주민 수(2026-10) |
| `map_x`, `map_y` | 점의 자리. 전국 지도 기준 0~1000의 정수. 시군구 주민이 모여 사는 중심(2024 인구 1km 격자의 주민 수 가중 평균 자리). y는 아래로 갈수록 커진다(SVG 그대로). |

| `level_access`, `level_medical`, `level_elder`, `level_infant`, `level_child`, `level_disabled`, `level_library` | 7개 영역의 판정: 부족/비슷/넉넉/경계 |

- `access_source`가 "직선거리(2026)"이면 의료거리의 기준 문구를 "새로 생긴 구라 정부 값이 없어, 직접 잰 직선거리 기준(응급 10km·분만 20km·소아청소년과 10km 밖 주민 비율)으로 대신함. 잣대가 달라 기준선(50%, 10%) 가까이 있으면 판정을 붙이지 않음"으로 바꾼다. (영종구가 42.3%인데 "경계"인 이유다.)
- 판정이 "경계"이면 카드에 "기준선 가까이 있어 판정을 붙이지 않았습니다"를 적는다.
- 숫자는 소수 첫째 자리까지(값이 1 미만이면 둘째 자리까지) 보여 준다. 이 "보여 주는 글자"를 만드는 함수를 하나 두고, 카드·중앙값·요약 검사가 모두 그 함수의 결과를 쓴다.

### 6.3 점의 색

- 전국·시도 지도: `lacking_count` 4 이상 빨강, 2~3 주황, 0~1 회색빛 파랑. (빨강·초록만으로 나누지 않는다: 색을 구별하기 어려운 사람을 위해)
- 점의 크기는 모두 같다(인구에 따라 키우지 않는다: 큰 도시가 나쁜 곳처럼 보이지 않게).
- 점마다 `<title>`에 "시도 시군구 · 부족 N개"를 넣고, 점은 8.3으로 가는 링크다.

## 7. Gemma4 요약문 규칙

1~3단계에서 만든 방식을 그대로 넓힌다.

- **주는 것**: 지역 이름, 숫자 7, 부족한 영역 수, **부족한 영역의 이름만**, 그리고 부족한 영역의 지표를 "이름표: 보여 주는 숫자" 꼴로. 이름표에는 숫자를 쓰지 않는다(예: "주민 천 명당 의사 수: 0.66", "노인 만 명당 노인복지관 수: 0").
- **받는 것**: 두 문장. 첫 문장은 7개 영역 가운데 몇 개가 부족한지와 그 이름, 둘째 문장은 받은 지표 가운데 하나를 골라 그 숫자를 말한다. 부족이 0개면 한 문장만.
- **검사** (`logic.py`, Gemma4를 부르지 않고 테스트 가능):
  1. 답에서 숫자(`\d+(?:\.\d+)?`)를 모두 꺼내, 하나하나가 "준 숫자의 글자"(7, 부족한 영역 수, 준 지표의 보여 주는 숫자)와 **글자로 같아야** 한다. 원래 값(0.661)이 아니라 보여 주는 글자(0.66)로 견준다.
  2. 답에 나온 영역 이름은 모두 부족한 영역이어야 한다. 7개 영역 이름을 하나씩 답에서 찾아, 부족 목록에 없는 이름이 있으면 탈락(부족이 0개면 영역 이름이 하나라도 나오면 탈락). 이름이 서로 겹치는 글자는 없다("의료거리"와 "의료자원"은 네 글자 전체로 찾는다).
  3. 200자 이하, 빈 답이 아님.
  4. 숫자 7이 들어 있어야 하고, 부족한 영역이 있으면 그 개수도 들어 있어야 한다("잘 모르겠습니다" 같은 뜻 없는 답을 거른다).
- **검사에 걸리거나 서버 오류**: 미리 정한 문장을 쓴다. "신안군의 7개 영역 가운데 5개가 부족으로 나왔습니다. 부족한 영역은 의료거리, 노인돌봄, 영유아보육, 장애인·복지, 도서관입니다." 부족이 0개면 "제물포구의 7개 영역 가운데 부족으로 나온 영역은 없습니다." 이 문장은 위 검사를 통과해야 한다(테스트로 확인).
- 화면에는 지금처럼 "AI 요약" / "기본 요약"을 표시한다.
- 지금의 도서관 요약 함수(`build_summary_prompt` 등)는 `/library`에서 그대로 쓴다. 격차맵용은 이름이 다른 새 함수로 만든다.

## 8. 화면

### 8.1 첫 화면 `/`

```
공공복지격차맵
우리 지역의 의료·돌봄·도서관, 다른 곳과 견주면?

[ 전국 점 지도 (SVG) ]
 ● 부족 4개 이상  ● 2~3개  ● 0~1개

[시도 ▼][보기]
지역을 선택해주세요

부족한 영역이 많은 곳
 1. 인천광역시 미추홀구  5개
 2. 전남광주통합특별시 신안군  5개 ...(10곳)

자료와 판정 방법 안내(접힌 글)
```

- 점 하나가 시군구 한 곳이다. 색은 부족한 영역 수로 세 단계.
- 색에만 기대지 않도록 범례와 아래 목록을 함께 둔다.
- 시도를 고르고 [보기]를 누르면 8.2로 간다(`/?sido=...`).
- 목록의 지역 이름은 8.3으로 가는 링크다. 부족 수가 같으면 인구가 많은 순.
- "지역을 선택해주세요" 문구는 지금 테스트와 같은 글자를 쓴다.

### 8.2 시도 화면 `/?sido=시도이름`

- 고른 시도의 점만 크게 그린 지도. 점 옆에 시군구 이름을 적는다(겹치면 이름은 생략해도 됨: 구현자 판단).
- 그 아래에 그 시도의 시군구 목록: 이름, 부족 영역 수, 경계 영역 수. 이름은 8.3으로 가는 링크.
- 스마트폰에서는 점이 작아 누르기 어렵다. 지역으로 들어가는 주된 길은 이 목록이다.

### 8.3 지역 화면 `/region?region=시도|시군구`

```
전남광주통합특별시 신안군   인구 42,337명
7개 영역 중 5개 부족, 1개 경계
유형: 농어촌형 (두 유형의 중간에 가까움)

AI 요약: ...두 문장...        ← "AI 요약" 또는 "기본 요약" 표시

┌ 의료거리 · 부족 ──────────────┐
│ 응급실·분만실·소아청소년과에 제때 가기 어려운 주민 85.5% │
│ (정부 기준. 50% 이상이면 부족)                          │
│ 이 지역 안에는 분만 가능한 기관이 없습니다.              │
└──────────────────────────────┘
┌ 의료자원 · 경계 ──────────────┐
│ 의사 0.66명 / 주민 1천 명  (전국 중앙값 1.3명)           │
│ 약국 2.6곳 / 주민 1만 명   (전국 중앙값 ...)             │
│ 인구 구조가 비슷한 지역과 견준 판정                      │
└──────────────────────────────┘
 ... 카드 7장 ...

알아 둘 점 (해당할 때만)
- ...
```

- 카드 7장의 순서: 의료거리, 의료자원, 노인돌봄, 영유아보육, 아동돌봄, 장애인·복지, 도서관.
- 카드마다: 영역 이름, 판정, 지표 값과 전국 중앙값, "무엇에 비해" 한 줄.
- 판정 색: 부족=빨강, 경계=회색, 비슷=노랑, 넉넉=초록. 색과 함께 글자를 반드시 적는다.
- 의료거리 카드에는 판정과 상관없이, `no_delivery_room`이 1이면 "이 지역 안에는 분만 가능한 기관이 없습니다."를, `no_er`이 1이면 "이 지역 안에는 지정 응급의료기관이 없습니다."를 한 줄씩 적는다.
- 도서관 카드에는 "도서관 자세히 보기" 링크를 둔다. 주소는 `/library?region=` 뒤에 `library_region` 칸의 값을 붙인다. 그 칸이 비어 있으면 링크를 내지 않는다.
- 안내 문구(지금 앱과 같은 글자):
  - `region`이 없음 → "지역을 선택해주세요"
  - 시도가 빔 → "시도를 선택해주세요", 시군구가 빔 → "시군구를 선택해주세요"
  - 자료에 없는 지역 → "등록된 지역 정보가 없습니다"
- 8.2에서 자료에 없는 시도가 오면 전국 화면(8.1)을 그리고 "등록된 지역 정보가 없습니다"를 보여 준다.

### 8.4 도서관 자세히 `/library?region=시도|시군구`

- 지금의 도서관 카드 화면 그대로. 위쪽 탭을 없앤다.
- 지역을 고르는 양식이 보내는 곳을 `/`에서 `/library`로 바꾼다(`templates/index.html`의 `<form action="/">`). 안 바꾸면 지역을 골랐을 때 새 첫 화면으로 가 버린다.
- "← 격차맵으로" 링크를 둔다. 가는 곳은 첫 화면 `/`이다(도서관 자료와 격차 자료의 지역 이름이 다른 곳이 있어 지역 화면으로 바로 잇지 않는다).
- 화면 아래에 "1~5단계에서 만든 화면이며, 지자체가 공공데이터포털에 낸 자료 기준입니다"라고 적는다.

### 8.5 금연 지원 `/smoking`

- 화면은 그대로 두되 위쪽 탭만 없앤다. 다른 화면에서 이리로 오는 링크는 없다.

## 10. 하지 않는 것과 한계

**하지 않는 것**
- 끌고 확대하는 지도, 시군구 경계 색칠(경계선 자료가 없고 JavaScript를 쓰지 않는다)
- 현재 위치(GPS) 사용, 지역 이름 검색, 로그인, 개인 정보 저장
- 앱 안에서 원자료를 다시 집계하는 일(집계는 분석 폴더에서 끝낸다)
- 금연 지원 표를 격차맵과 잇는 일

**이렇게 되면 실패**
- 색만 보고 "이 지역은 나쁜 곳"으로 읽히는 화면. 판정의 뜻(무엇에 비해 부족한가)이 카드마다 글로 적혀 있어야 한다.
- 요약문이 카드에 없는 숫자나 판정을 말하는 것.
- 위쪽에 도서관·금연 탭이 남아 앱이 세 가지 일을 하는 것처럼 보이는 것.

**점 지도가 이상하면**

10단계(스마트폰 확인)에서 아래 가운데 하나라도 해당하면 진짜 지도로 바꾸는 것을 사용자와 다시 정한다.

- 전국 지도에서 한반도 모양으로 보이지 않는다.
- 수도권·부산 점이 한 덩어리로 뭉쳐 색을 읽을 수 없고, 시도 화면에서도 풀리지 않는다.
- 사용자가 보고 "이상하다"고 판단한다.

바꿀 때 필요한 것(지금은 하지 않음): 2026년 행정구역이 반영된 시군구 경계 자료 확보, JavaScript·외부 자료 금지 규칙의 변경, 지도 함수 교체.

**한계**

- 판정은 "인구에 견준 시설·인력의 양"이다. 질, 운영 시간, 실제 이용 편의는 담지 못한다.
- "비슷한 지역에 비해" 판정하는 4개 영역은 기준선 근처 십여 곳이 계산할 때마다 "경계"를 드나든다. 부족이 넉넉으로 뒤집히는 일은 없었다.
- 의료거리는 정부의 2023년 이동시간 값이고, 나머지는 2024~2026년 자료라 기준 시점이 섞여 있다.
- 노인돌봄과 장애인·복지는 인구 구조로 설명되지 않아 전국과만 견준다.
- 인천의 새 4개 구는 일부 값이 추정이다.
- 점의 자리는 행정구역의 한가운데가 아니라 주민이 모여 사는 중심이다. 경계선은 그리지 않는다.
- 요약문 검사는 숫자와 영역 이름만 본다. 이름표의 낱말이 바뀐 것(예: "노인 만 명당"을 "주민 만 명당"으로 쓴 것)은 잡지 못한다. 실제 Gemma4의 답 16개 가운데 1개에서 보았다.
- 인천처럼 섬이 멀리 떨어진 시도는 시도 지도에서 본토의 점들이 한쪽에 뭉친다. 지역으로 들어가는 길은 지도 아래의 목록이다.

## 11. 색칠 지도와 화면 다듬기 (2026-11-22 변경, 11단계부터)

### 11.1 왜 바꾸나
- 10단계에서 스마트폰으로 본 결과, 점 지도는 점이 작고 겹쳐 지역을 구분하기 어려웠다. 앞에서 정해 둔 "점 지도가 이상하면" 조건에 해당한다.
- 화면이 브라우저 기본 모양이라 정렬이 맞지 않고, 이동이 파란 밑줄 글자뿐이라 누르는 자리가 보이지 않았다.
- 그래서 (1) 시군구 경계 모양에 색을 칠하는 지도로 바꾸고, (2) 화면을 다듬는다. JavaScript 와 외부 CSS·CDN 을 쓰지 않는 조건은 그대로다.

### 11.2 지도 자료
앱이 읽는 파일 두 개를 더한다. 분석 폴더의 `분석_격차맵/export_map_paths.py` 로 만들어 넣었고, 앱은 읽기만 한다.

| 파일 | 칸 | 뜻 |
| :--- | :--- | :--- |
| `data/map_paths.csv` (230줄) | `sido`, `sigungu` | 시도, 시군구 |
| | `label_x`, `label_y` | 이름표를 쓸 자리(주민이 모여 사는 중심) |
| | `d_low` | 전국 지도용 경계 모양(SVG path 의 d 값, 거칠게) |
| | `d_high` | 시도 지도용 경계 모양(자세하게) |
| `data/map_views.csv` (17줄) | `name` | "전국" 또는 시도 이름 |
| | `x`, `y`, `w`, `h` | 그 지도에서 보여 줄 범위(SVG viewBox 의 네 숫자) |

- 출처: 국가데이터처 SGIS 행정구역 경계(2025년 2분기 기준, 공공데이터포털 15129688).
- 일반구는 시로 합쳤다. 2026년에 생긴 인천 4개 구는 읍면동 경계를 새 구에 맞게 다시 묶었다.
- 원래 점이 600만 개라 좌표를 반올림해 줄였고, 아주 작은 섬은 뺐다.
- 시도 지도의 범위는 그 시도 주민의 1%도 안 사는 시군구(울릉군·옹진군)를 빼고 잡았다. 그 지역은 지도 밖에 걸릴 수 있고, 아래 목록으로 들어간다.

### 11.3 지도 그리는 규칙
- 주소: `/?sido=시도이름&domain=영역키`. 둘 다 없어도 된다. `domain` 은 access, medical, elder, infant, child, disabled, library 가운데 하나이고, 그 밖의 값은 없는 것으로 본다.
- 전국 지도는 `d_low`, 시도 지도는 그 시도의 줄만 골라 `d_high` 로 그린다. 보이는 범위는 `map_views.csv` 의 값을 viewBox 로 쓴다.
- 색
  - `domain` 이 없을 때(부족한 영역 수): 4개 이상 `#c0392b`, 2~3개 `#e67e22`, 0~1개 `#5b82b5`
  - `domain` 이 있을 때(그 영역의 판정): 부족 `#c0392b`, 경계 `#7a828c`, 비슷 `#b7791f`, 넉넉 `#2e7d5b`
- 구역마다 지역 화면으로 가는 링크를 걸고, `<title>` 에 "시도 시군구 · 부족 N개"를 넣는다.
- 시도 지도에는 `label_x`, `label_y` 자리에 시군구 이름을 쓴다. 전국 지도에는 이름을 쓰지 않는다.
- 색에만 기대지 않도록 범례와 아래 목록을 함께 둔다.

### 11.4 화면 다듬기
- 꾸밈 규칙을 `static/style.css` 한 파일로 모으고 모든 화면이 이 파일을 쓴다(우리 서버의 파일이라 외부 CSS 가 아니다).
- 모든 화면 맨 위에 앱 이름이 있는 머리띠를 둔다. 누르면 첫 화면으로 간다.
- 내용은 같은 폭의 흰 상자에 담아 왼쪽 끝과 여백을 맞춘다. 지표는 이름을 왼쪽에, 값을 오른쪽에 맞춘다.
- 이동은 글자 링크가 아니라 단추로 한다. 목록은 한 줄 전체가 누르는 자리이고 오른쪽에 판정 딱지와 화살표를 둔다. 누르는 자리의 높이는 44px 이상.
- 판정은 색 딱지로 보여 준다(부족·경계·비슷·넉넉). 딱지 안에 글자를 반드시 적는다.
- 지역 화면 맨 위에 7개 영역의 판정을 한눈에 보는 요약 상자를 둔다.
- 첫 화면의 지도 위에 시도 선택, 영역 선택, [보기] 단추를 한 줄로 둔다.
- "기준선 가까이 있어 판정을 붙이지 않았습니다"는 회색 안내로, "분만 가능한 기관이 없습니다"·"지정 응급의료기관이 없습니다"는 붉은 안내로 보여 준다.

### 11.5 테스트의 예외
- 지도 방식을 바꾸므로 `test_app.py` 의 11·13·15·16·17번(점의 수와 옛 목록 모양을 확인하던 것)은 새 화면에 맞는 내용으로 바꾼다. 이유를 PROGRESS.md 에 적는다.
- `test_logic.py` 의 130개는 고치지 않는다. 점 지도 함수(`map_points`, `build_map_svg`)는 지우지 않고 남긴다.

## 12. GitHub Pages 용 정적 페이지 (2026-11-26 변경, 14단계부터)

### 12.1 왜 바꾸나
- 13주차 강의에서 결과물을 GitHub Pages 주소로 스마트폰에서 열도록 배웠다. GitHub Pages 는 파일을 그대로 보내 주기만 하고 파이썬을 실행하지 않아서, Flask 로 만든 화면은 올릴 수 없다.
- 여는 주소: `https://아이디.github.io/ai-course/week15/`

### 12.2 방식
- 계산은 지금처럼 파이썬(`logic.py`)이 한다. PC 에서 한 번 실행해 결과를 자료 파일 `site_data.js` 로 내보낸다.
- 화면 조각은 Flask 화면(`/`, `/?sido=…`, `/region?region=…`)을 PC 에서 그려 `<div class="container">` 안쪽만 잘라 낸 것이다. 그래서 `templates/` 와 `test_app.py` 를 그대로 쓴다.
- 스마트폰 브라우저의 JavaScript 는 화면 조각을 끼워 넣고, 고른 영역에 맞게 지도 색을 바꾸고, 요약문을 받는 일만 한다. 판정·순위·중앙값 같은 계산은 하지 않는다.
- JavaScript 는 `view.js` 와 `summary.js` 에만 쓴다. 외부 CSS·CDN·새 라이브러리는 쓰지 않는다.
- Flask 판(`app.py`, `templates/`, `test_app.py`)은 지우지 않는다. 자료 파일을 만드는 데 쓴다.

### 12.3 파일

| 파일 | 내용 |
| :--- | :--- |
| `fetch_summaries.py` | 230곳의 요약문을 gemma4 에게 미리 받아 `data/gap_summaries.csv` 에 쓴다 |
| `build_site.py` | 화면 조각을 자르고 링크를 바꾸는 작은 함수들, 요약 검사에 쓸 값 뽑기 |
| `make_site.py` | Flask 화면을 그려 조각·지도 색·요약을 모으고 `site_data.js` 를 쓴다 |
| `site_data.js` | `const SITE = {...};` 자료 파일. `make_site.py` 가 만든다 |
| `index.html` | 머리띠와 화면 조각을 끼울 빈 자리 |
| `summary.js` | 요약 받기 |
| `view.js` | 주소 읽기, 화면 조각 끼워 넣기, 지도 색 바꾸기 |
| `test_static.py` | 위 파이썬 파일의 테스트 |

### 12.4 주소
서버가 없으므로 `?` 대신 `#` 뒤의 글자로 화면을 고른다.

| 주소 | 화면 |
| :--- | :--- |
| `#` 또는 없음 | 전국 지도 |
| `#sido=서울특별시` | 시도 화면 |
| `#domain=access`, `#sido=서울특별시&domain=access` | 고른 영역의 판정으로 칠한 지도 |
| `#region=서울특별시\|관악구` | 지역 화면 |

없는 시도나 지역이면 "등록된 지역 정보가 없습니다"를 보여 준다. 없는 영역이면 전체 영역으로 본다.

### 12.5 요약문
1. 지역 화면을 열면 요약 자리에 "AI 요약을 받는 중입니다"를 보여 준다.
2. 13주차 강의의 `ask` 함수로 실습 서버의 gemma4 를 부른다. 6초 안에 답이 없으면 실패로 본다.
3. 답이 오고 검사를 통과하면 이름표 "AI 요약"과 받은 글을 보여 준다.
4. 실패했거나 검사에 걸리면 PC 에서 미리 받아 둔 글과 그 이름표를 보여 준다.

- 미리 받아 두기: 지역마다 gemma4 에게 최대 3번 묻고 `is_good_gap_summary` 를 통과한 글을 쓴다. 3번 모두 걸리면 기본 문장(`gap_fallback_summary`)을 쓴다.
- 이름표는 세 가지다: "AI 요약"(스마트폰에서 방금 받은 글), "AI 요약 (미리 받아 둔 글)", "기본 요약".
- 브라우저의 검사는 `is_good_gap_summary` 와 같은 규칙이다. 써도 되는 숫자와 쓰면 안 되는 영역 이름은 파이썬이 미리 뽑아 자료 파일에 넣는다.
- 2026-11-26 현재 실습 서버는 다른 주소의 웹페이지가 보내는 요청을 허용하지 않아(CORS), 브라우저에서 부르면 바로 실패하고 미리 받아 둔 글이 나온다.

### 12.6 넣지 않는 것
- 도서관 자세히 화면과 금연 화면은 정적 페이지에 넣지 않는다. 도서관 자세히는 1~5단계의 기준이라 격차맵 카드와 판정이 다르게 나올 수 있다. Flask 판에는 남아 있다.

### 12.7 테스트의 예외
- `test_logic.py` 150개와 `test_app.py` 38개는 고치지 않는다. `logic.py`, `app.py`, `templates/` 도 고치지 않는다.
- `data/` 폴더에는 `fetch_summaries.py` 가 `gap_summaries.csv` 를 새로 쓰는 것만 된다. 있던 CSV 는 고치지 않는다.
- JavaScript 는 파이썬 테스트로 확인할 수 없다. 브라우저에서 Flask 화면과 같은지 견주어 확인하고 PROGRESS.md 에 적는다.
