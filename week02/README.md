## 어텐션을 프로그래밍을 모르는 사람에게 설명하는 글
긴 글을 통째로 외운 다음 기억만으로 옮겨 쓰면 앞부분은 흐려진다. 어텐션은 외우는 대신 원문을 옆에 펼쳐두고, 한 단어를 쓸 때마다 필요한 곳을 다시 들여다보는 방식이다. "school"을 쓸 때는 "학교에"르ㄹ, "go"를 쓸 때는 "간다"를 집중해서 보는 방식이다. 어디를 봐야하는지는 사람이 알려준게 아니라 기계가 수많은 예시를 보며 스스로 익힌것이다. 이 필요한 곳을 골라 보는 방법이 지금 AI가 말을 알아듣는 핵심 어텐션이다.
