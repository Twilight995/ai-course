# 1. 기술과 파일 구성

- Python 3.10 이상, Flet 1.0. 다른 패키지는 쓰지 않는다. 파이썬에 들어 있는 모듈(random, json 등)은 쓸 수 있다.
- main.py는 이 폴더에 있는 main.py 뼈대를 그대로 가져와 넓혀서 만든다. logic.py에는 뼈대가 없고 처음부터 만든다.
- 뼈대에 나온 Flet 문법만 쓴다. 뼈대에 없는 Flet 클래스, 인자, 속성은 쓰지 않는다. 기억하고 있는 Flet 문법은 옛 버전의 것이므로 쓰지 않는다.
- 특히 다음은 Flet 1.0에 없으므로 쓰면 오류가 난다: `ft.app(...)`, `ft.colors`, `ft.alignment.center`, `ft.ElevatedButton`, `Button(text=...)`, `page.window_width`, `ft.UserControl`, `TextField(error_text=...)`

| 파일명 | 스펙 |
| :--- | :--- |
| SPEC.md | 스펙 |
| logic.py | 계산과 판정. Flet을 import하지 않는다. 입력을 받아 결과를 돌려주는 함수만 있다 |
| main.py | 화면. 뼈대를 넓힌 것. 계산은 전부 logic.py의 함수를 불러서 한다 |
| test_logic.py | logic.py의 함수를 검사한다. 실행하면 통과와 실패 수를 출력한다 |

# 2. 동작 규칙

- 소문자는 항상 들어간다.
- 대문자, 숫자, 특수문자(!@#$%^&*)는 체크 상자로 고른다.
- 길이는 4 이상 32 이하다. 벗어나면 만들지 않고 안내 문구를 보여 준다.
- 체크한 종류의 문자는 적어도 하나씩 들어간다.
- 잘못된 입력의 판단은 `logic.py`에서 하며, `logic.py`는 그에 맞는 안내 문구를 돌려준다.
- 입력값이 비어 있으면 "길이를 입력해주세요"라는 문구를 돌려준다.
- 입력값이 숫자가 아니거나(문자, 소수 포함) 앞뒤 공백이 포함되어 있으면 "숫자만 입력해주세요"라는 문구를 돌려준다.
- 입력값이 4 미만 또는 32 초과이면 "4~32 사이로 입력해주세요"라는 문구를 돌려준다.
- 오류가 발생하면 결과 칸은 비운다.
- [다시 만들기] 버튼은 현재 선택된 길이와 체크 상태를 그대로 유지한 채 새 비밀번호를 만든다.

# 3. 화면

1. **길이 입력창**: `TextField`
2. **체크 상자 세 개**: 대문자 포함, 숫자 포함, 특수문자 포함
3. **[만들기] 버튼**: 파란색
4. **결과 칸**: 생성된 비밀번호를 보여주는 `Text`
5. **[다시 만들기] 버튼**: 회색
6. **안내 문구**: 빨간색 `Text`
